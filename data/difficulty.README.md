# difficulty.csv 記入ガイド

`data/difficulty.csv` は、総合難易度スコアの**第3軸**として編集部が出典付きで投入する
難易度データです。ここに行を足すと、その資格のスコア精度が自動で上がります
（空でもOK。その場合は合格率・学習時間の2軸で算出されます）。

## フォーマット

```csv
slug,difficulty,source
c-3624,55,日商の合格率推移と他資格比較に基づく編集部評価
c-1203,82,電験三種：科目別合格率・標準学習時間1000h前後を根拠に評価
```

| 列 | 必須 | 内容 |
|----|------|------|
| `slug` | ✅ | `certifications.csv` の slug（例: `c-3624`）。一致しない行は無視されます |
| `difficulty` | ✅ | **0〜100 の数値。高いほど難しい**。絶対値ではなく相対順位として使われます |
| `source` | 推奨 | 数値の根拠・出典。**捏造禁止**。一次情報や公開統計に基づくこと |

- ヘッダー行は必須。`slug` か `difficulty` が空の行、`difficulty` が数値でない行はスキップされます。
- 値が無い資格は行ごと省略してOK（無理に全件埋めない）。

## 推奨スケール（0〜100 の目安）

難易度の「絶対値」ではなく**掲載資格間の相対位置**を表すパーセンタイル正規化に通すため、
厳密さより**順序の一貫性**が重要です。下記を基準に揃えてください。

| 値 | 体感 | 代表例の目安 |
|----|------|------|
| 90–100 | 最難関国家資格 | 司法試験・公認会計士・弁理士・社労士クラス |
| 75–89 | 難関 | 一級建築士・電験三種・中小企業診断士クラス |
| 55–74 | 中上級 | 宅建士・簿記2級・基本情報技術者クラス |
| 35–54 | 中級 | 簿記3級・ITパスポートクラス |
| 1–34 | 入門〜易 | 各種検定3級・入門資格クラス |

> スコアは**全体内パーセンタイル**に変換されるため、同じ分野内で
> 「AはBより難しい」という**順序が崩れない**ことを最優先に。絶対値は多少ブレてOK。

## 値の決め方（推奨手順）

1. **一次情報を集める** — 公式の合格率推移、標準学習時間、受験者層、出題範囲。
2. **近い既存資格と比較** — 「この資格は宅建より難しく診断士より易しい」のように
   アンカー資格に挟んで位置を決めると一貫性が保てます。
3. **数値化して `source` に根拠を書く** — 「電験三種：標準1000h・科目合格率20%前後」など、
   後から検証できる形で残す。憶測のみの値は入れない。

## source の書き方

- 何を根拠にしたかを一文で。可能なら出典名・統計の年度を含める。
  - 良い例: `日商簿記2級 合格率推移(2020-2024 平均約20%)と標準学習時間250h`
  - 良い例: `電験三種 科目別合格率・標準学習時間1000h前後を根拠に編集部評価`
  - 避ける: `なんとなく難しいから`（検証不能）

## スコアへの反映

- このデータは `合格率(実効)`・`学習時間` と並ぶ**主要シグナル（重み1.0）**として
  加重平均に入ります。
- 主要シグナルが**2つ以上**そろうと、各資格ページの**信頼度が「高」**になります。
- 投入後は `python3 tools/build_pages.py` でビルドし、`python3 tools/validate.py` で検証。
  ビルドは決定的なので、同じ入力なら同じ出力になります。

---

### 関連する算出ロジック

スコア算出の本体は `tools/build_pages.py` の `build_difficulty_rank()`。
4シグナル（合格率・学習時間・難易度データ・受験資格）を全体内パーセンタイルに正規化 →
加重平均 → 主要シグナル数に応じた中央値への収縮(shrinkage) → 全体／分野内ランキング、
の順で計算しています。
