# 重点項目（合格率・受験者数）カバレッジ TODO

主要資格のうち **合格率 / 受験者数** が未充足のものを、公式一次ソースの URL 付きで整理した作業リスト。
本セッションでは実行環境の egress ポリシーにより下記の公式ドメインへ直接到達できず（`403`/接続拒否）、
検索スニペットに実数値が展開されない・第三者ブログのみが数値を提示する、という理由で確定できなかった。
**ネットワーク制限のない環境で各 URL を開けば、`data/overrides.csv`（合格率）と `data/exam_details.csv`（受験者数）に反映できる。**

方針（このリポジトリの原則）:
- 公式の一次情報のみ採用。第三者ブログ（seibishi.me / musenboya.com 等）の数値は不採用。
- 合格率と受験者数は **同一年度・同一検定段階** でペアにする。
- 「候補値（未確認）」は検索インデックス上に現れた公式PDF由来と思われる値。**現物照合してから**投入すること。

## ② 恒久的に空でよいもの（無試験 / 制度上・方針上 非公表）

これらは公式一次情報が存在しないため、**空欄のままが正しい**（無理に埋めない）。

- **英検（級別）** `c-3307` 1級 / `c-3308` 準1級 / `c-3309` 2級: 日本英語検定協会は2016年度以降、**級別合格率・級別志願者数を非公表**。全体の年間志願者数のみ公表。
- **全経簿記** `c-3627`/`c-3628`/`c-3629`: 全国経理教育協会は科目別合格率の**レンジ**のみ（https://zenkei.or.jp/PassRate ）。単一回の確定値・受験者数は取得困難。
- **MOS** `c-3815`〜`c-3840`: オデッセイ コミュニケーションズは合格率を**非公表**（随時CBT・問題非固定のため）。
- **栄養士** `c-2002`: 国家試験ではなく**養成施設卒業で免許交付**（栄養士法第2条）。合格率・受験者数の概念なし。
- **食品衛生管理者** `c-1101`: 試験ではなく**資格者・所定学科修了＋講習で任用**（食品衛生法第48条）。
- **司書 `c-2701` / 司書補 `c-2702` / 学芸員 `c-2703` / 学芸員補 `c-2704`**: 大学等での**単位取得・講習修了**で資格付与。試験制度なし。
- **消防設備点検資格者** `c-4503` 第1種 / `c-4504` 第2種: 登録講習会＋修了考査型（日本消防設備安全センター）。合格率・受験者数**非公表**。
- **高圧ガス移動監視者** `c-5209` / `c-5211`: 講習＋検定型（KHK）。合格者番号のみ公表で、集約合格率・受験者数は**非公表**。
- **衛生工学衛生管理者** `c-2204`: 登録講習会＋修了試験型（中災防等）。修了試験合格率は**非公表**。

## 暫定値レイヤー（`data/provisional.csv`）

上記①の多くには、第三者集計に基づく **暫定値（非公式・参考）** を `data/provisional.csv` に投入済み。
公式値が空のときだけ、詳細ページに橙色「暫定」チップ＋注記付きでフォールバック表示される
（正本の `overrides.csv` / `exam_details.csv` は公式値のみを保持）。
各 `official_url`（本ファイル①）で公式値を確認できたら、`overrides.csv` に正式値として昇格し、
`provisional.csv` の該当行を削除する運用。
