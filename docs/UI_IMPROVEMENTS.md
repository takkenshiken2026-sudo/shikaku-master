# UI改善 調査レポート（現行「資格マスター」デザイン）

調査日: 2026-07-06
対象: main（PR #120 時点）の生成サイト全ページ種
方法: 生成HTML/CSS/JSのコードレビュー＋ローカル実表示（デスクトップ1280px / モバイル390px）＋ブラウザ操作テスト

## 総評

現行デザインはトークン化されたCSS・グローバルナビ・ヒーロー検索・カードUI・ページネーション・skip link・focus-visible など土台がよくできている。一方で、**機能が壊れている箇所（P0）が2つ**、情報優先度の問題（P1）がいくつか見つかった。本ブランチで下記のとおり対応済み。

## 調査結果と対応状況

### P0: 機能バグ

| 問題 | 状態 |
|---|---|
| **比較ページが恒久的に「読み込み中…」** — `build_compare()` の body が f-string でなく、`<script src="{asset_url('', 'assets/compare.js')}">` が未評価のまま出力され、JSが一切読み込まれない | ✅ **修正済み**（f-string化） |
| **検索が略称・かな・表記ゆれに非対応** — 検索欄の例示「宅建」で0件、「FP」1件、「エクセル」「でんけん」0件。`name` の部分一致のみで `display_name` も見ていない | ✅ **修正済み** — `data/aliases.csv`（略称・カナ・読み・表記ゆれ 61件）を新設し JSON に `aliases` を出力。JS側に正規化（小文字化・全角英数→半角・ひらがな→カタカナ・空白/中点除去）を実装し、name＋display_name＋aliases を横断マッチ |
| **比較機能に入口がない** — compare-bar.js と CSS は実装済みだが「＋比較」ボタン（`.cmp-add-btn`）を出力するページが存在しない | ⏸ **対応保留**（オーナー判断でスキップ。比較導線は「よく比較される資格」（vs ページ）に集約されている状態） |

### P1: 情報優先度・検索体験

| 問題 | 状態 |
|---|---|
| 詳細ページで PR枠「この資格の対策サイト」が資格情報より上にあり、受験料・合格率がファーストビュー外（モバイル全長 約9,500px） | ✅ **修正済み** — PR枠を資格情報セクションの直後に移動し、h1直下に**KPIファクトカード**（受験料・合格率・難易度・学習時間・受験資格。長い値のタイルは自動スキップ）を追加 |

## 実装メモ

- 検索用エイリアスは `data/aliases.csv`（slug / aliases（`;`区切り）/ note）。**表示には使わず検索マッチのみ**に使用。
- JS の正規化仕様: 小文字化 → 全角英数→半角 → ひらがな→カタカナ → 空白・中点・括弧の除去。クエリと索引文字列の双方に適用。
- 詳細ページのファクトカードは値が長い場合（受験料22字超など）にタイルを自動省略し、2枚未満ならセクション自体を出さない。
- すべて `tools/build_pages.py` 側の修正（site/ は生成物）。`python3 tools/validate.py` は整合性エラーなしを確認済み。
