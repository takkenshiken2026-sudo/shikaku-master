# 資格区分（type）の分類規約

本データの `type`（国家 / 公的 / 民間 / 要確認）と `type_confidence`（high / medium / low）の
判定基準を定める。新規追加・再照合時はこの規約に従う。

## type の定義

| type | 定義 |
|------|------|
| **国家** | 法令に基づく免許・国家試験・国家検定。例：法令で定められた免許（医師・電気工事士等）、技能検定（○級○○技能士）、指定試験機関方式の国家試験 |
| **公的** | 次のいずれか。①省庁・自治体が法令に基づき実施／登録／指定／任用する資格。②法律に基づく公的団体（日本商工会議所・各地商工会議所、中央職業能力開発協会＝JAVADA 等）が実施する検定。③**省庁（特に文部科学省）が後援する検定**（社会通念上「公的資格」と扱われるもの）。④大臣登録試験・大臣認定の技能審査 |
| **民間** | 民間団体・企業が独自に実施し、上記の公的関与がないもの。ベンダー資格（Microsoft/Cisco/Oracle 等）、業界団体・NPO・私企業の独自検定 |
| **要確認** | 制度廃止・新規取得不可、資格名でなく募集要項上の条件表記、同名の実施団体が複数併存、名称が一般名詞で特定不能 等、上記に一意に当てはめられないもの |

## 「省庁後援検定」の扱い（グレー領域の確定方針）

文部科学省等が「後援」する検定は、実施主体が公益法人・NPO・私団体であっても、
社会通念上「公的資格」と称されることが多い（英検・漢検・日商簿記・秘書検定・全経/全商各検定 等）。
本データでは **③の規約に従い、省庁後援検定は原則「公的」** とする。

ただしこの区分は出典により揺れがあるため、`type_confidence` は当該資格の社会的扱いが
明確なら high、解釈が大きく割れる場合のみ medium とする。

## type_confidence の運用

- **high**：一次情報・実施団体公式、または本規約の明確な当てはめにより type が確定できるもの。
- **medium**：規約上の区分は定めたが、**事実関係そのものが出典間で割れる**もの（例：同名で
  国家講習と民間評価試験が併存し、どちらを指すか確定できない資格）。
- **low**：`type=要確認`。一意に確定できないもの。

## 判定の参考

- 一次情報の確認は `tools/recheck.py export` で対象を抽出し、実施団体公式で裏取りする。
- 判定の根拠・出典は `data/factcheck_log.csv` に記録する。
