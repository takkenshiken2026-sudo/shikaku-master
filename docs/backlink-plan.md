# 被リンク設置キット（対策サイト → 資格マスター）

自社の各対策サイトから総合サイト `shikaku-master.jp` へ相互リンクを設置するための設計です。**被リンクは各対策サイト側で設置**します（本体リポジトリでは作れません）。

> 方針転換のポイント：**全ページ共通の「関連サイト」欄で13サイトを総当たり相互リンクするのは非推奨**です。同一運営者・全ページ共通・相互・キーワードアンカーの組み合わせはリンクネットワークの典型で、Googleに**評価されない（discount）かリンクスキーム扱い**になり、労力の割にリターンが出ません。ユーザーに分かりにくいリンク＝Googleが無視するリンク、です。

## 設計の基本（安全かつ効く）
1. **本文中の文脈リンクを主役に**（各サイト1〜2本）。解説記事・コラムの関連文脈から、資格マスターの該当ページへ。ユーザーに有益＝SEOでも評価される。
2. **フッターは“運営メディア”1リンクだけ**（全ページ共通で置くならこれのみ）。リンク先は**ハブ＝資格マスターのトップ**、アンカーは素直に「資格マスター」。
3. **ハブ&スポーク構造**（各専門サイト→ハブ中心）。スポーク同士（対策サイト間）の総当たり相互リンクはしない。
4. **アンカーは分散・自然に**、数を絞る。同一アンカーの大量設置はNG。

---

## A. フッター用（全サイト共通で置くのはこれ1本のみ）
各対策サイトのフッターに置くなら、ハブへの控えめな1リンクに留めます。

```html
<a href="https://shikaku-master.jp/">資格マスター（資格情報サイト）</a>
```

※ フッターから資格マスターの“深いページ”へキーワードアンカーで大量に張らないこと。

## C. やってはいけないこと（リスク回避）
- 全ページ共通フッターに、13サイトの相互リンクを一括羅列する
- 深いページへキーワード完全一致アンカーを大量設置する
- 対策サイト同士（スポーク間）を総当たりで相互リンクする
- ユーザーにとって不自然・無関係な位置にリンクを置く

## D. 本命（owned網は“補助”）
新規ドメインの権威は**外部からの自然な被リンク**が主役です。owned網の相互リンクは小さな下支えと位置づけ、並行して「引用されるデータ記事」「業界ディレクトリ登録」「プレス・SNS」等で外部リンクを獲得してください。

## E. 設置後チェック
1. リンク先が200で開くか（sitemap掲載ページ）
2. Search Console（資格マスター側）で被リンク認識（反映まで数週間）
3. アンカー・設置箇所が自然か（不自然なら撤去）
