# 被リンク設置キット（対策サイト → 資格マスター）
自社の各対策サイトから、総合サイト `shikaku-master.jp` の関連ページへ相互リンクを設置するための一覧とスニペットです。**各対策サイト側のリポジトリ/管理画面で設置**してください（本体リポジトリでは被リンクは作れません）。
## 設置ルール（重要・SEO品質）
- **全ページ一律のフッターリンクは避ける**（リンクスキーム扱いのリスク）。コラム/解説記事など**文脈に沿った本文中**、または各サイトの「関連サイト」欄1か所に設置。
- **アンカーテキストは自然に分散**（下の候補をローテーション）。同一アンカーの大量設置はNG。
- **関連性の高いページ同士**をつなぐ（例：宅建対策サイト→宅建の詳細ページ）。
- リンクは通常の do-follow でOK（自社メディア間の自然な相互リンク）。ただし数は各サイト1〜3本程度に抑え、質重視で。
- まずは需要の大きいサイト（宅建・危険物・衛生管理者・証券外務員・運行管理者）から着手。

## 宅建対策サイト
- リンク元サイト: https://takken-master.jp/
- **主リンク先**: https://shikaku-master.jp/c/c-3207.html （宅地建物取引士）

```html
<p>より詳しい試験情報は、資格情報サイト「資格マスター」の<a href="https://shikaku-master.jp/c/c-3207.html">宅地建物取引士の受験料・合格率・難易度</a>もあわせてご覧ください。</p>
```

## 設置後のチェック
1. リンク先URLが 200 で開くか（sitemap掲載ページ）。
2. Search Console（資格マスター側）で被リンクが認識されるか（数週間かけて反映）。
3. アンカー・設置箇所が自然か（不自然な大量設置は撤去）。
